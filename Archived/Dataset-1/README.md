# Archived: Dataset-1 (Initial Baseline Generation)

This folder contains the complete initial version (V1) of the LMIS labour market datasets generated for SIH26246.

### Files in this Archive:
* **`lmis_employment_monthly_2016_2025.csv`**: Monthly panel across 11 districts and 5 sectors (6,600 rows × 45 columns).
* **`lmis_employment_quarterly_2016_2025.csv`**: Quarterly panel across 11 districts and 5 sectors (2,200 rows × 44 columns).
* **`lmis_employment_state_monthly_2016_2025.csv`**: State-level monthly aggregations (2,400 rows × 21 columns).
* **`DATA_SOURCES_AND_METHODOLOGY_V1.md`**: V1 data sources, formulas, and data dictionary.
* **`generate_lmis_datasets_v1.py`**: Python script used to generate Dataset-1.

> **Active Production Version:**  
> The new enhanced V2 dataset is located in the root directory:
> * `lmis_employment_monthly_2016_2025_v2.csv` (7,200 rows × 64 features)
> * `lmis_employment_quarterly_2016_2025_v2.csv` (2,400 rows × 49 features)
> * `lmis_district_sector_kpi_summary_v2.csv` (60 rows × 14 features)
> * `DATA_SOURCES_AND_METHODOLOGY_V2.md`
