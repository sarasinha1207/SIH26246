# Superseded data – do not use

`v1_synthetic/` holds the first synthetic LMIS panel and its methodology note, kept only as an audit trail for the
Phase 2 defect findings (see `docs/phases/PHASE_2_DATA_COLLECTION.md`). It was replaced by the v2 panel in `data/raw/`.
Its generator is `src/data_generation/legacy/generate_lmis_master_dataset_v1.py`.

Nothing here may be used for training, evaluation or comparison. This folder is separate from `Archived/`, which holds the
earlier dataset that is also off limits.
